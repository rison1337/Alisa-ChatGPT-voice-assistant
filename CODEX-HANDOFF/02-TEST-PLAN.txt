ПЛАН ЖИВОЙ ПРОВЕРКИ WINDOWS
Выполнять по порядку, фиксировать факт, а не предполагать успех.
Настройки виртуальной машины и виртуальное железо не трогать.

0. ПОДГОТОВКА
[ ] Прочитать AGENTS.md и 01-CONTEXT.txt.
[ ] Windows 10/11 x64, обычный пользователь, локальный NTFS, Chrome/Edge.
[ ] Скопировать весь комплект в рабочую папку Windows, не только .cmd.
[ ] Записать версию Windows, терминала и браузера без персональных данных.
[ ] Владелец вводит IP/порт/пароль SSH и VPN, если потребуется, только в CLI.
    Не копировать SSH-ключ Linux или пароль из старого контекста.

1. ЦЕЛОСТНОСТЬ / УСТАНОВКА НА ПК
[ ] START-WINDOWS.cmd --check-only: пакет цел, нет SSH и изменений колонки.
[ ] START-WINDOWS.cmd --no-run: программа в LocalAppData, без UAC и pip.
[ ] Повторить --no-run: тот же пакет пропускается, state не меняется.
[ ] Команда %LOCALAPPDATA%\AlisaVoice\alisa.cmd --help работает.
[ ] Режим bridge отклоняется: текущая Windows-сборка только native.
[ ] Папка с пробелами/кириллицей и Windows-профиль с кириллицей.
[ ] DACL state доступна только текущему пользователю и SYSTEM.
[ ] Запустить Windows host-тесты встроенным Python (команда в 01-CONTEXT).

2. SSH / СОХРАНЕНИЕ ПОДКЛЮЧЕНИЯ
[ ] Первый запуск спрашивает адрес, порт, пользователя и пароль.
[ ] Неизвестный SSH-хост требует явного подтверждения отпечатка.
[ ] Неверный пароль даёт понятную ошибку без утечки в лог/на экран.
[ ] Сохраняется собственный ключ, пароль в config отсутствует.
[ ] После закрытия/открытия CLI сохранённое подключение работает без пароля.
[ ] Ввод другого адреса доступен; ошибку подключения можно исправить в меню.
[ ] Отказ от pin не записывает ключ. Смену ключа проверять только на
    тестовом локальном SSH-сервере, не менять ключ действующей колонки.

3. ПЕРВЫЕ ПРОВЕРКИ КОЛОНКИ
[ ] Сначала status/doctor/storage и сохранение текущих настроек.
[ ] Root, модель Лайт 2, прошивка и необходимые компоненты проверены.
[ ] Свободное место отображается в МиБ; недостаток показывается только
    при реальной нехватке. Ничего не стирать ради имитации нехватки.
[ ] Проверка IP делается с колонки; RU предлагает VPN, не-RU проходит.
    Пользователь не хочет HTTP 403 и «голос не проверен» в этой проверке.

4. МАСТЕР И ОБНОВЛЕНИЕ
[ ] Отмена до применения не меняет файлы/запуск на колонке.
[ ] Мастер по очереди предлагает VPN, автозапуск, фразы и LED.
[ ] Существующая установка явно называется обновлением.
[ ] Совпадающие файлы не передаются заново; состояние и чаты сохраняются.
[ ] Меню, стрелки, Enter, Esc, Ctrl+C работают без мусора и мерцания.
[ ] Справка и информационные пункты подгружаются при выборе без лишнего Enter.
[ ] Ошибки не выбрасывают секреты/traceback на экран.

5. ВХОД В CHATGPT — ГЛАВНЫЙ НЕПРОВЕРЕННЫЙ УЧАСТОК
[ ] Первое окно обычного Chrome/Edge позволяет пройти сайт и войти.
[ ] Личный браузер пользователя остаётся открыт и не меняется.
[ ] Вход определяется автоматически, без Enter/ручного копирования cookies.
[ ] Повторный вход с уже сохранённой браузерной сессией тоже определяется.
[ ] SQLite Cookies при открытом окне читается либо реализован корректный
    другой способ ожидания, без закрытия окна до завершения входа.
[ ] После входа импорт сохраняет обновляемые cookies и проверяет их
    на колонке. В stdout, отчёте и временных общих папках нет токенов.
[ ] Ctrl+C, закрытие окна, занятый профиль, ошибка Cloudflare или сети
    сохраняют прежнюю рабочую сессию. Нет зависших собственных процессов.
[ ] Вход через localhost SSH-forward/VLESS проходит корректно.
[ ] Старый аккаунт: условия Voice уже приняты; новый: при необходимости
    пройти их с владельцем. Проверять фактический ответ, а не тариф.
[ ] Free/Plus проверять только с участием владельца, Go оставить непроверенным.
[ ] Смена аккаунта и logout — только по команде владельца; отсутствие
    смешивания истории аккаунтов и восстановление Алисы при ошибке.

6. РАБОТА НАТИВНОГО КЛИЕНТА
[ ] Короткий verify даёт настоящий голосовой ответ и завершает тест.
[ ] «Алиса, открой чат», «закрой чат», «создай новый чат»,
    «открой предыдущий чат» работают с сохранёнными стандартными фразами.
[ ] Изменение фраз применяется быстро и без перезапуска разговора.
[ ] Выбор голоса работает; изменение сохраняется.
[ ] При выборе LED демо видно на колонке, отмена возвращает прежнюю LED.
[ ] Возврат к Алисе восстанавливает штатный звук, микрофоны и индикацию.
[ ] При остановке VPN/потере связи или лимите GPT нет зависания режима:
    возвращается Алиса, при настроенном VPN прямого обхода нет.

7. VPN / АВТОЗАПУСК
[ ] Без VPN не ставится ненужное ядро, существующий VPN не удаляется молча.
[ ] Отдельная vless:// и доступная подписка: выбор сервера, валидация,
    установка и запуск на колонке. Реальную ссылку предоставляет владелец.
[ ] Синтетические windows/test-data не являются рабочими VPN-серверами.
[ ] Xray xHTTP и sing-box выбираются правильно. Проверять и код, и вывод
    валидатора, особенно Xray при недоступном пути к конфигу.
[ ] Start/stop/status, переключение автозапуска и удаление VLESS работают.
[ ] Удаление касается только установленных этой программой VPN-файлов.
[ ] Включение автозапуска native действует на колонке, а не на Windows.
[ ] Перезагрузка колонки с согласованным моментом не требует ПК после
    сохранённого входа. Не перезагружать неожиданно во время прослушивания.
