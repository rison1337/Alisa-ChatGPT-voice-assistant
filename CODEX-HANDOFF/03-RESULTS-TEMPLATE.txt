ALISA VOICE — РЕЗУЛЬТАТЫ WINDOWS, 30.10.2026

ТЕКУЩИЙ РЕЗУЛЬТАТ
Повторный браузерный вход, настоящий голос, сохранение данных и автозапуск
после перезагрузки прошли на этой Windows и этой Станции Лайт 2.
Проверены режим без VLESS и рабочий VLESS XHTTP/Reality через Xray.
На момент завершения проверок VLESS включён и обязателен только для GPT;
автозапуск VPN и native включён, колонка в idle, доступна Алиса.
После переноса комплекта владелец попросил удалить только native-клиент
колонки для самостоятельной проверки установки через этот CLI.
Результат этой отдельной операции: 04-USER-REINSTALL.txt и соответствующий
JSON в evidence. Приложение на ПК, SSH, аккаунт и чаты сохраняются.
Не считать это общей поддержкой всех Windows, Chrome, тарифов или Go.

АУДИО И ГРАНИЦЫ ПРОВЕРКИ
Подтверждение voice verify требует одновременно текста ответа от сервера
и полученного звука, а не только phase=active. Критерии не ослаблялись.
В успешных прогонах ALSA underruns=0, WebRTC NetEq. Долгий непрерывный
разговор отдельным стресс-тестом не проверялся. Владелец подтвердил
произнесённые команды open/new/previous/close, звук GPT, подсветку и ответ
штатной Алисы после закрытия GPT.
Kernel ip в этой прошивке не поддерживает route get ... mark, а IPv6 table
показывает корректно через table all. Для проверки использованы реальные
правила/таблицы, реальная остановка Xray и реальный блокированный запрос.

ИСПРАВЛЕНИЯ В КОДЕ
- SQLite-проба реально закрывает соединение, не удерживая Windows handle.
- При live lock Cookies readiness определяется через UIAutomation только
  собственного окна; затем реальная сессия проверяется отдельно на колонке.
- Обычное окно и импорт отключают расширения/sync, используют одинаковый
  нормальный Windows User-Agent; обычное окно не получает DevTools-флаги.
- Части auth cookies разных доменов не смешиваются: выбирается целый набор
  одной семьи/домена/пути; предпочтение каноническому .chatgpt.com.
- Отмена закрывает только собственный Windows native браузер и сохраняет вход.
- Xray требует и код 0, и Configuration OK до передачи на колонку.
Новые live-тесты не потребовали дополнительных правок native-клиента.
