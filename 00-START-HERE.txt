ALISA VOICE — WINDOWS, НАТИВНЫЙ РЕЖИМ
Локальная тестовая сборка. На GitHub не опубликована.

1. Откройте START-WINDOWS.cmd двойным щелчком.
2. Программа скопируется в папку текущего пользователя и откроет CLI.
3. Введите IP, порт, пользователя и пароль SSH вашей Станции Лайт 2.
   Root и SSH должны работать заранее. Установщик их не получает.
4. Пройдите мастер. Для входа в ChatGPT нужен установленный Chrome или Edge.
   Пароль ChatGPT вводите только на сайте в открывшемся отдельном окне.
5. После установки нативного клиента компьютер для его работы не нужен.

Windows 10/11 x64. Администратор и установка системного Python не нужны.
Python, библиотеки и готовые программы для колонки находятся в комплекте.
Windows-мост в эту сборку не входит.

Это подготовка к живой проверке в Windows, а не завершённая Windows-версия.
Пока подтверждены работа Windows Python под Wine, SSH, передача файлов,
проверка пакета и установка программы на компьютер. Вход Chrome/Edge и
полный мастер должны быть проверены на настоящей Windows.

Повторный запуск: START-WINDOWS.cmd, либо
  %LOCALAPPDATA%\AlisaVoice\alisa.cmd

Проверка целостности без установки и подключения к колонке:
  START-WINDOWS.cmd --check-only

Установка только на компьютер без запуска CLI и подключения к колонке:
  START-WINDOWS.cmd --no-run

Папка программы: %LOCALAPPDATA%\AlisaVoice\app
Настройки и SSH-ключ: %LOCALAPPDATA%\AlisaVoice\state
Обычное обновление программы сохраняет эту папку данных.

На колонке уже может работать текущая версия. Не сбрасывайте колонку,
не удаляйте root, SSH, аккаунт или чаты ради теста установщика.

ДЛЯ CODEX В WINDOWS
Сначала прочитать AGENTS.md, затем CODEX-HANDOFF\01-CONTEXT.txt
и CODEX-HANDOFF\02-TEST-PLAN.txt. Полные исходники находятся в этой папке.
Не менять настройки виртуальной машины, её образы и виртуальное железо.
Не публиковать Windows-код до отдельной команды владельца.
