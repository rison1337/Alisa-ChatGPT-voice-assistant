# Лайт 1: нативный режим

Адаптация основана на [PR #1 от HuHguZ](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/pull/1), коммит `df1b536eb161fded34657f7864e5e5ad5dd834b9`. Автор проверял одну `Yandex Station Micro v1.2` 28 октября 2026 года. Это сведения автора PR; в этой ветке собственной Лайт 1 для аппаратного прогона нет.

Root и SSH должны работать заранее. Допускается только нативный режим. Мост на Лайт 1 не проверен и блокируется даже при установленном `socat`.

Другая читаемая сборка Лайт 1 допускается с предупреждением; она остаётся непроверенной. Неизвестная модель, отсутствующие компоненты и ошибки целостности пакета останавливают установку. [Политика совместимости](firmware-compatibility.md).

## Что установил автор PR

- Сигнатура `YandexVqeC_GetOutputChannelData` совместима с готовым `vqe_tap.so`. Штатный движок читает обработанный канал типа 6, индекса 0, блоками по 512 кадров при 16 кГц. При речи Алисы эхо на нём подавлялось.
- `aliced:9875` передаёт совместимые состояния и распознанную команду. Готовый `native_agent.so` обрабатывал живую команду открытия чата.
- `tts_gate.so` подходит для подавления штатной речи в GPT. Аудиотракт использует `alice_native_tts` и ALSA softvol/dmix.
- Клиент `alisa-standalone` работал без пересборки, использовал около 10 МиБ RSS в разговоре. `native verify` получил настоящий ответ без ALSA underrun. Проверялся автозапуск.

Эти результаты относятся к указанной сборке и не подтверждают все ревизии Лайт 1.

## Отличия адаптации

На Лайт 1 нет аппаратного `mute-switch` в debugfs. Старый клиент воспринимал это как выключенный микрофон и отправлял тишину. Новый `run.sh` включает `mute_gpio.so` только для `yandex,station-micro` при отсутствии этой строки. Модуль перенаправляет только чтение `/sys/kernel/debug/gpio` на небольшой файл состояния. Запись, другие пути и мутация через флаги `open` не перенаправляются. Зависимость `libdl` сохранена для glibc 2.30.

**Программная кнопка отключения микрофона Лайт 1 в GPT отдельно не проверена.** Совместимость потока и успешный голосовой ответ не подтверждают работу этой кнопки.

Индикатор и демо выбирают LED-префикс `micro` или `plum`. Сохранены восстановление штатных LED-триггеров, анимации и режим ожидания речи. На Linux проверены обе схемы в фикстурах sysfs; это не замена аппаратному прогону.

## Установка с Linux и Windows

Используется общий CLI: выберите нативный режим и укажите SSH. В Windows локальный пакет запускается через `START-WINDOWS.cmd`; в нём собственный Python и Paramiko. Вход выполняется через обычное окно Edge/Chrome и сохраняется автоматически. Отдельный `windows_login.py` из PR не включён: сохранён путь входа нашего Windows-установщика, проверенный на Лайт 2.

Windows-проверка из PR и наш прогон Лайт 2 — разные источники свидетельств. Полная цепочка нового пакета на Лайт 1 ещё требует прогона. При ошибке сессии или проверки браузера повторите вход через CLI; срок действия серверных разрешений не гарантируется.
