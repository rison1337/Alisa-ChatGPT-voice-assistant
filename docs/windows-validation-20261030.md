Комплект `AlisaVoice-Windows-Return-20261030` проверен в Linux без публикации.
Внешние SHA-256: 885 файлов совпали. Внутренний Windows manifest: 844 файла
совпали. Код приложения, тесты и бинарники совпадают с локальной веткой
`windows/native-installer` после a783925. Новые отличия — три handoff-документа,

Вне внешнего manifest найдены только два созданных Python __pycache__;
посторонних исполняемых исходников и отсутствующих файлов не обнаружено.

## Подтверждения возвращённого Windows-прогона

Окружение: одна Windows 11 Pro x64 10.0.26300, PowerShell 5.1, Edge
156.0.4314.50, embedded Python 3.13.17; готовые root/SSH на Plum.
По переданным JSON и журналам прошли:

- Браузерный вход с проверкой и сохранением сессии на колонке, напрямую и
  через SSH-forward к SOCKS/VLESS колонки; собственные окна и listener закрыты.
- Голос с текстом ответа и звуком, NetEq, без ALSA underruns в коротких проверках.
- Настройка, повтор, удаление и повторная установка XHTTP/Reality VLESS/Xray;
  аккаунт, чаты, selected, SSH и неизвестный контрольный файл сохранены.
- При реальном завершении Xray во время вызова возвращена Алиса за 0,455с.
  IPv4/IPv6 блокирующие маршруты сохранены, реальный GPT-запрос заблокирован,
  запуск без обязательного VPN отклонён. После запуска VPN голос восстановлен.
- Реальная перезагрузка без VLESS и с обязательным VLESS: клиент стартовал
  без команды запуска с ПК, голос после загрузки подтверждён.
- Пользователь подтвердил open/new/previous/close, звук, LED и штатную Алису.
- 24 Windows host-теста и 64 переносимых теста; 11 исключений перечислены явно.
  Полная исходная общая suite в Windows не была зелёной и не заявляется таковой.

По запросу владельца после проверки native был удалён для самостоятельной
установки. Это последний шаг возвращённого отчёта, а не вечное состояние
устройства. При нашем отдельном read-only запросе клиент уже снова запущен:
`phase=idle`, `agent_connected=true`, `login_saved=true`, `error` пуст.
В рамках проверки комплекта колонка не переустанавливалась и не перезапускалась.

## Оставшиеся границы

Не проверены Windows 10, Chrome, отдельные аккаунты Free/Plus/Go, новый
Voice onboarding/MFA, смена аккаунта/logout, реальная подписка с несколькими
серверами и длительный непрерывный разговор. Настоящий Windows-профиль с
кириллицей не равен отдельному синтетическому LOCALAPPDATA. Успешные новые
вызовы не доказывают устранение прежних периодических ICE/WebRTC таймаутов:
нового исправления native-транспорта в комплекте нет.

Windows-версия остаётся локальной тестовой сборкой. КВМ, её настройки и диски
не запускались и не изменялись. Публикация/push/release не выполнялись.
