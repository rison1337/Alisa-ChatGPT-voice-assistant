# Установка Linux

Нужны Linux x86_64, Python 3.10+, обычный Chromium и доступ к колонке по SSH. Python-библиотеки интерфейса входят в пакет: pip, venv и компилятор для установки готового релиза не нужны. Настройки пользователя не входят в архив.

## Локальная установка

Из папки подготовленного проекта или распакованного релиза:

```bash
./install-linux.sh
~/.local/bin/alisa
```

Программа устанавливается в `~/.local/share/alisa-voice`, команда — в `~/.local/bin/alisa`. Если `~/.local/bin` уже находится в PATH, достаточно `alisa`. Обновление заменяет только программу; настройки хранятся отдельно.

Для готового локального архива и соседнего файла SHA-256:

```bash
sh bootstrap-linux.sh --archive /путь/alisa-voice-linux.tar.gz
```

Опция `--no-run` устанавливает CLI без открытия меню. Bootstrap сверяет SHA-256 архива, допустимые пути, состав пакета и хеши файлов перед запуском установки. Не нужны права root для самой программы. Готовый архив доступен в [GitHub Releases](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/releases/latest).

## Пакеты компьютера

CLI предлагает установить отсутствующие компоненты. Поддержаны команды менеджеров следующих семейств; полный прогон выполнен только на CachyOS:

| Семейство | Общие компоненты | Дополнительно для моста |
|---|---|---|
| Arch / CachyOS / Manjaro | openssh, chromium | libpulse, xorg-server-xvfb, xorg-xauth, opus |
| Debian и системы с apt-get | openssh-client, chromium | pulseaudio-utils, xvfb, xauth, libopus0 |
| Fedora и системы с dnf | openssh-clients, chromium | pulseaudio-utils, xorg-x11-server-Xvfb, xorg-x11-xauth, opus |

Нужен работающий звуковой сервер PipeWire/PulseAudio. Установщик добавляет клиентские утилиты, не заменяет существующий звуковой сервер.

Используется обычный Chromium с доступом к локальному профилю, X11/XWayland и Native Messaging. Snap/Flatpak и Google Chrome отдельно не проверены; их взаимозаменяемость с системным Chromium не заявляется. Если дистрибутив предлагает Chromium только в контейнере, автоматическая установка полного моста пока не подтверждена.

## Что проверит мастер

Нативный режим доступен для Лайт 1, Лайт 2 и Станции 2 (`yandexmidi`); мост — только для Лайт 2. Станция Миди (`cucumber`) в этот список не входит. На Станции 2 мастер пропускает настройку подсветки GPT: для неё пока нет драйвера.

1. Адрес, порт, отпечаток SSH и root-доступ; после входа создаст отдельный ключ для последующих подключений.
2. Модель, архитектуру и читаемость maind/VQE. Неизвестная пара SHA-256 допускается с предупреждением; неизвестная модель или отсутствующий компонент останавливают установку. Предупреждение не подтверждает совместимость звука.
3. Место на компьютере и колонке, временные файлы обновления и запас.
4. Внешний IP выбранного режима: колонка для native, компьютер для bridge. RU предлагает VPN; неизвестная страна не считается успешной проверкой.
5. Выбранные фразы, подсветку, автозапуск и VLESS нативного клиента.
6. Вход в ChatGPT и настоящий короткий голосовой ответ.

## Данные и удаление

Аккаунты, ключ подключения и настройки находятся в `~/.local/state/alisa-voice`. В нативном режиме сессия также хранится на колонке. Обычное удаление программы сохраняет вход и чаты; выход из аккаунта — отдельная команда. SSH и root не удаляются. Компоненты перед удалением копируются в приватный каталог резервных копий.

Нативный режим и мост имеют отдельные настройки, одновременно колонкой управляет один режим. Переключая режим, сначала остановите предыдущий. Команды и устройство VPN описаны в [справочнике](cli-reference.md).

## Обновление поверх Linux 0.2.0

В 0.2.0 ещё нет новой команды `alisa update`. Удалять приложение и очищать настройки не нужно.

1. Закройте голосовой чат и остановите текущий режим через старый CLI.
2. Повторите установочную команду:

```bash
curl -fsSL https://raw.githubusercontent.com/rison1337/Alisa-ChatGPT-voice-assistant/main/bootstrap-linux.sh | sh
```

3. Новый CLI откроет существующие настройки. Для обновления компонентов колонки выберите режим → «Установка и обслуживание → Настроить / переустановить». Сохранённый вход будет использован повторно.
4. Дальше новые версии устанавливаются через «Обновления программы» или `alisa update`.

Установщик заменяет приложение в `~/.local/share/alisa-voice`, сохраняя прежнюю папку. Настройки, SSH и профили в `~/.local/state/alisa-voice` остаются. Исходный каталог проекта также не нужно удалять.

Для локального архива скачайте Linux TAR и соседний `.sha256` из [релиза](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/releases/latest) и используйте bootstrap из того же комплекта:

```bash
sh bootstrap-linux.sh --archive /путь/alisa-voice-linux.tar.gz
```

Публичные архивы скачиваются без авторизации GitHub; ключи разработчика для установки не нужны.
