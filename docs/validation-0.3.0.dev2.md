# Проверка предпросмотра 0.3.0.dev2

30 октября 2026, Linux/CachyOS и Windows Python через Wine. Новая версия включает нативную Лайт 1, Windows-установщик, updater и установку неизвестной прошивки с предупреждением.

- Общие тесты Linux: 149 успешно.
- Windows host-тесты под Wine: 29 успешно, включая настоящий `alisa.cmd`, launcher, worker и возврат кодов при откате.
- Updater под Wine: 18 запущено, 17 успешно, Linux worker пропущен по платформе.
- Политика прошивок под Wine: 10 запущено, 9 успешно, Linux-мост пропущен по платформе.
- Использована точная пара SHA-256 из issue #2. Она допускает установку с предупреждением, но сохраняет признак непроверенного ABI.
- Проверены обязательные отказы, целостность повреждённого пакета, dry-run без записи и отсутствие второго запрета хеша в Linux-мосте.

На флешке получен `AlisaVoice-Windows-Updates-Return-20261030-ExitCodeFix`: проверены 944 внешние суммы и 866 файлов manifest. Возвращённые исправления launcher и connecting импортированы, прежние локальные файлы и безопасные журналы сохранены отдельно. Свидетельства настоящего Windows-прогона dev1: [результаты](windows-updates-validation.md#код-возврата-windows). Они не являются аппаратным тестом новой политики прошивок.

Работающий клиент колонки, её прошивка, Wi-Fi и сохранённые входы в этой доработке не менялись. Новую Лайт 2 из issue и Лайт 1 аппаратно не проверяли. Разрешение установки не гарантирует звук на всех версиях; это явно указано в CLI и [политике](firmware-compatibility.md).

Для пробного перехода с Windows dev1 подготовлен `TRY-UPDATE-WINDOWS.cmd`: он использует установленный launcher и показывает обычное предложение обновления из локального ZIP с соседним SHA-256. Выбор пользователя требуется до установки. Самого публичного релиза с новой версией ещё нет; публичный API обновлений не подменялся.

Для Linux 0.2.0 предусмотрена [установка нового CLI поверх прежнего](linux-install.md#обновление-поверх-linux-020), поскольку старая версия ещё не умеет `alisa update`. Пользовательские данные хранятся отдельно от заменяемой программы.

## Публичная 0.3.0

После подготовки предпросмотра установленный клиент владельца на Linux сообщил `complete`, версия `0.3.0.dev2`. Для публичной 0.3.0 изменены номер версии, описание, инструкции установки и метаданные пакетов; исходный код аудиоклиента не менялся. Публичный релиз позволяет CLI предпросмотра увидеть настоящую более новую версию через обычный GitHub API.
