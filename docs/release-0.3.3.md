# Alisa Voice 0.3.3

Добавлен нативный режим для **Яндекс Станции 2 (`yandexmidi`)** с установкой из Linux и Windows. Нужны готовые root и SSH. Это Станция 2, а не Станция Миди (`cucumber`). Поддержка основана на [PR #3 от serbo26-lab](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/pull/3); исходные коммиты автора сохранены.

- Установщик распознаёт модель, подготавливает её профиль и сохраняет настройки подключения. Автор PR сообщил о голосовом диалоге, командах открытия/закрытия и автозапуске на одном устройстве с прошивкой `0.369.1.46.4778263334.20261013.295`. Для других сборок действует предупреждение о непроверенной совместимости.
- Обработанный микрофон Станции 2 получает усиление ×16; уровни Лайт 1/2 остаются прежними. Усиление применяется к копии звука, исходный VQE-буфер не изменяется. Некорректные параметры не вызывают тишину или максимальную громкость.
- Учтены другие имена и полярность переключателя микрофона. При неизвестном состоянии передача микрофона отключается. Длинные GPIO-списки читаются целиком с ограничением ресурсов; одновременные чтения получают независимые снимки.
- Подсветка GPT на Станции 2 пока недоступна: настройки скрыты, управлением штатной подсветкой продолжает заниматься Алиса. Мост доступен только на Лайт 2; неподдерживаемая модель отклоняется до установки.
- Исправлена контрольная сумма `run.sh` в комплекте; новый тест проверяет настоящий установочный payload всех трёх моделей.

Обновление: `alisa update` в Linux или установленный `alisa.cmd update` в Windows. Настройки, вход ChatGPT, чаты, SSH, VPN и автозапуск сохраняются. После обновления при необходимости проверьте текущие IP и порт колонки.

Автоматические проверки: 186 тестов Linux, пять новых проверок установки и 29 тестов Windows host/launcher/updater под Wine. Оба установочных архива проверены по внешним и вложенному native manifest. Собственного аппаратного прогона Станции 2 и Лайт 1 нет; результаты автора PR не распространяются на все устройства и прошивки.

На настоящей Лайт 2 выполнено обновление `0.3.2 → 0.3.3` обычным Linux-updater. Файлы входа, чатов, фраз, подсветки и автозапуска при обновлении совпали; профиль не включает усиление Станции 2. Получен голосовой ответ GPT: 875 входных аудиоблоков, 332 непустых блока микрофона, 82 блока воспроизведения, `muted_frames=0`, сбоев ALSA — 0. После закрытия GPT штатная Алиса успешно озвучила тестовую фразу. После полной перезагрузки колонки нативный клиент автоматически вернулся в `idle` с сохранённым входом. Голосовая проверка выполнялась в сети с выходом DE; исходная сеть с RU дала `ice_gather_timeout` и на прежней версии.
