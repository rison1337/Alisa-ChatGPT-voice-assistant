# Alisa Voice 0.3.5

**Яндекс Станция Мини 2** теперь поддерживает нативный режим и Linux-мост. Основа — [PR #8 от roman-dynin](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/pull/8); все восемь исходных коммитов автора сохранены.

- Модель определяется по `yandex,station-mini2`. Проверенная автором прошивка — `0.369.1.46.4793643989.20261020.299`; другие читаемые сборки допускаются с предупреждением.
- Все шесть зон кольца работают в GPT и демо: три логические зоны отображаются на физические пары. LED-часы не затрагиваются. Индикатор уступает кольцо прошивке при mute или неизвестном состоянии GPIO, возвращает триггеры и не стирает яркость предупреждения даже при завершении процесса.
- Для моста `socat` также ищется в `/data/opt/entware/bin/socat`.
- Исправлена первая установка: отсутствие клиента отображается как «остановлен», временное `state_unavailable` при старте не обрывает мастер. Ошибка загрузки уже установленного клиента с кодом 127 остаётся ошибкой.
- Исправлено восстановление триггеров кольца при завершении индикатора по сигналу.

Обновление: `alisa update` в Linux или установленный `alisa.cmd update` в Windows. Установленные компоненты колонки обновляются вместе с программой; вход, чаты, SSH, VPN, автозапуск и настройки сохраняются. Аудиомодули и уровни усиления этим выпуском не меняются. Поддержка Лайт 1/2 и Станции 2 сохранена; Windows-мост пока не поддерживается.

Автор PR подтвердил нативный диалог, команды, VQE, ответ без ALSA underrun, возврат Алисы и Linux-мост на одной Мини 2. Наши проверки: **221 тест основного приложения в Linux**, **100 тестов моста**, **29 тестов Windows host/launcher/updater под Wine**, **17 проверок модели и 5 проверок установочного payload в Windows Python под Wine**. Оба индикатора также проверены в BusyBox настоящей Лайт 2 на временных файлах, без запуска голосового ответа. Linux- и Windows-пакеты проверены по внешним SHA-256, пакетным manifest и вложенному native manifest.

Нового аппаратного прогона Мини 2, её автозапуска после перезагрузки и установки на неё из настоящей Windows у сопровождающего проекта нет. Новое поведение кольца при mute проверено на файловых стендах, включая наследование настоящего `mute_gpio.so`. [Подробности модели](mini2.md).
