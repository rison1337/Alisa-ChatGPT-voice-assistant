# Alisa Voice 0.3.11

- После успешной установки мастер показывает ошибку дополнительного голосового теста и открывает меню. Повторить тест можно в разделе «Проверки».
- В Linux нативный клиент можно переустановить с входом, сохранённым на колонке, без установки Chromium, Xvfb и xauth. Для нового входа мастер предлагает только отсутствующие пакеты.
- Диагностика нативного Voice различает ответ HTTP 403 с HTML, подтверждённый запрос браузерной проверки и другие ответы HTTP 403. Изолированный тест принимает синтетическую речь и проверяет путь передачи звука без микрофона и динамика колонки. [Инструкция по диагностике](native-network.md#изолированная-проверка-сеанса).

По [issue #14](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/issues/14) улучшена диагностика. Устойчивое исправление `internal_error` на Лайт 1 и Миди пока не подтверждено.

## Обновление

Закройте голосовой чат. Выполните `alisa update` в Linux или `alisa.cmd update` в Windows. Также можно принять предложение при запуске CLI. Для обновления компонентов колонки нужен доступ по SSH. Мастер сохраняет вход, чаты и настройки. [Подробности обновления и отката](updates.md).
