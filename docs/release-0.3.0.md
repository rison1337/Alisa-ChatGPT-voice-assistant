# Alisa Voice 0.3.0

**ChatGPT Voice на Яндекс Станции Лайт 1 и Лайт 2.** Нативный клиент работает на колонке после установки; Linux-мост использует браузер на компьютере. Нужны заранее полученные root и SSH, API-ключ не требуется.

## Изменения

- Нативный установщик Windows x64 с готовыми Python и SSH-библиотеками, входом через Edge/Chrome и автоматическим сохранением сессии.
- Нативная Лайт 1: GPIO и подсветка по [PR #1 от HuHguZ](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/pull/1). Оригинальные коммиты и авторство сохранены.
- Обновления Linux/Windows через CLI: «Обновить», «Не сейчас», «Больше не спрашивать», ручная проверка и возврат уведомлений.
- Обновление приложения и компонентов установленных режимов с сохранением входа, чатов и настроек; откат при ошибке. Windows launcher возвращает настоящий код результата обновления.
- Неизвестная прошивка распознанной Лайт 1/2 допускается с предупреждением. Проверки модели, архитектуры, компонентов и целостности пакета сохраняются. Устранена блокировка установки из [issue #2](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/issues/2); звук на новой сборке из issue отдельно не подтверждён.

## Установка

Linux x86_64, Python 3.10+:

```bash
curl -fsSL https://raw.githubusercontent.com/rison1337/Alisa-ChatGPT-voice-assistant/main/bootstrap-linux.sh | sh
```

Windows x64: скачать `alisa-voice-windows.zip`, распаковать целиком и запустить `START-WINDOWS.cmd`.

## Обновление поверх старой версии

**Linux 0.2.0:** остановите текущий режим и повторите установочную команду выше. Новый CLI подхватит прежние настройки; выберите «Установка и обслуживание → Настроить / переустановить» для обновления компонентов колонки. Удалять `~/.local/state/alisa-voice` и повторно входить в аккаунт не нужно.

**CLI с поддержкой обновлений**, включая `0.3.0.dev2`: закройте голосовой чат, откройте приложение и выберите «Обновить». Для немедленной проверки:

```bash
alisa update
```

Windows: установленный `%LOCALAPPDATA%\AlisaVoice\alisa.cmd update`. Автоматической установки в фоне нет. Проверка при запуске кэшируется на 6 часов; ручная проверка получает сведения сразу.

## Проверки и ограничения

Политика неизвестных прошивок и транзакции установки проверены тестами Linux/Wine. На настоящем Windows 11 x64 / Edge с Лайт 2 пройдены установка, вход, голос, VLESS, обновление, откат и восстановление состояния. Владелец также успешно обновил Linux до предпросмотра `0.3.0.dev2`; переход поверх публичного Linux 0.2.0 проверен в изолированном окружении.

Лайт 1 аппаратно исследована автором PR; её программная кнопка микрофона в GPT требует отдельной проверки. Windows-мост, Windows 10, отдельный прогон Chrome и живой Go остаются непроверенными. Разрешение установки неизвестной прошивки не является подтверждением работы звука на всех версиях.
