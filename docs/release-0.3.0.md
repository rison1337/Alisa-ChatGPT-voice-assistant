# Alisa Voice 0.3.0 — описание для публикации

ChatGPT Voice на Яндекс Станции Лайт 1 и Лайт 2. Нативный клиент работает на колонке после установки; Linux-мост использует браузер на компьютере. Для обоих вариантов нужны заранее полученные root и SSH.

## Изменения

- Нативный установщик Windows x64 с готовыми Python и SSH-библиотеками, входом через Edge/Chrome и сохранением сессии.
- Нативная Лайт 1: адаптация GPIO и подсветки по [PR #1 от HuHguZ](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/pull/1). Авторство исходных коммитов сохраняется.
- Обновления через CLI: «Обновить», «Не сейчас», «Больше не спрашивать», ручная проверка и возврат уведомлений. Приложение и установленные компоненты обновляются с сохранением входа, чатов и настроек.
- Откат при ошибке; Windows launcher возвращает настоящий результат обновления и освобождает заменяемую папку.
- Неизвестная прошивка распознанной Лайт 1/2 допускается с предупреждением. Проверки модели, архитектуры, компонентов и целостности пакета сохраняются. Это снимает блокировку из [issue #2](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/issues/2), но не подтверждает звук на всех версиях.

## Установка

Linux x86_64: Python 3.10+, Chromium, готовые root/SSH. После публичной публикации:

```bash
curl -fsSL https://raw.githubusercontent.com/rison1337/Alisa-ChatGPT-voice-assistant/main/bootstrap-linux.sh | sh
```

Windows x64: скачать `alisa-voice-windows.zip`, распаковать целиком и запустить `START-WINDOWS.cmd`.

На Linux 0.2.0 сначала остановите текущий режим и повторите команду установки поверх старой. Затем выберите «Настроить / переустановить» для компонентов колонки. Настройки в `~/.local/state/alisa-voice` остаются. В новой версии дальнейшие обновления доступны через `alisa update`.

## Проверка приватного предпросмотра

Версия `0.3.0.dev2` пока выпускается в приватном `rison1337/Alisa-Voice-preview`. Для пробного обновления уже установленной dev1 скачайте Windows ZIP и `.sha256`, положите рядом `TRY-UPDATE-WINDOWS.cmd` и запустите его. Он откроет обычное предложение обновиться из проверяемого локального архива. До выбора «Обновить» программа не устанавливается.

На флешке файлы уже разложены в нужные папки. Не запускайте новый `START-WINDOWS.cmd` перед пробным апдейтом: он сразу установит новую программу и проверять переход с dev1 будет уже неоткуда. `START-WINDOWS.cmd` остаётся обычной установкой.

Результат Windows-установщика и updater подтверждён на одном Windows 11 x64 / Edge с Лайт 2. Политика неизвестной прошивки проверена на фикстурах Linux/Wine. Лайт 1 в этой ветке аппаратно не проверена, программная кнопка микрофона в GPT требует проверки. Windows-мост и живой Go остаются в плане.

Публичные merge/release и закрытие issue #2 выполняются после проверки предпросмотра владельцем. При закрытии issue нужно отметить снятую блокировку установки отдельно от аппаратной проверки аудио новой прошивки.
