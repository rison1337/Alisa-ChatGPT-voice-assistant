# Alisa Voice 0.3.4

Подсветка GPT на **Яндекс Станции 2 (`yandexmidi`)**: её панель из 88 светодиодов поддерживает радугу, цвета, пульсацию, выключение и живое демо в CLI Linux/Windows. Основой стал [PR #5 от serbo26-lab](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/pull/5); исходные коммиты автора сохранены.

- Настройка панели доступна в мастере и в «Настройках → Подсветка». Старое значение «Выключена» сохраняется: после обновления с 0.3.3 выберите нужный цвет. Индикация в паузах GPT по умолчанию выключена, её можно включить отдельно.
- Исправлены переходы после включения mute и при неизвестном GPIO: индикатор прекращает запись и не стирает красное предупреждение прошивки при выходе. Чужой кадр также сохраняется при закрытии GPT или завершении процесса.
- Постоянный цвет восстанавливается после обычной перерисовки прошивкой. Демо возвращает прежний кадр, если панель ещё принадлежит ему.
- Исправлен обрыв демо по SSH: увеличенный скрипт передаётся через stdin одного соединения, без длинного exec-запроса. Временный файл удаляется после завершения.

Обновление: `alisa update` в Linux или установленный `alisa.cmd update` в Windows. Вход, чаты, SSH, VPN, автозапуск и выбранные настройки сохраняются. Аудиомодули и уровни микрофонов этим выпуском не меняются.

Автор PR сообщил об аппаратной проверке панели на своей Станции 2. Наши проверки: файловые стенды панели/кольца и CLI; в BusyBox настоящей Лайт 2 — кадры RGBW через временный файл, перерисовка и mute; на её настоящем кольце — красный, радуга, пульсация, выключение и восстановление яркости/LED-триггеров после демо. Самостоятельной аппаратной проверки Станции 2 и Лайт 1 нет.

Проверки выпуска: **201 тест Linux**, **29 тестов Windows host/launcher/updater под Wine** и **5 проверок интеграции Станции 2 в Windows Python**. Linux- и Windows-архивы распакованы и проверены по внешним SHA-256, пакетным manifest и вложенному native manifest.

На настоящей Лайт 2 выполнено обновление **0.3.3 → 0.3.4** штатным Linux-updater: файлы входа/настроек, фразы, подсветка и флаги автозапуска сохранились. Получен голосовой ответ GPT через WebRTC NetEq без ALSA underrun, после закрытия клиент вернулся в `idle`. Воспроизведение панели на этой колонке проверялось через временный файл: 100 изменяемых кадров заняли 3,32 с, включая обмен командами по SSH; аппаратная скорость панели Станции 2 этим не измерялась.
