# Нативный голос и split tunneling

Проверка `alisa native network` определяет внешний IP запроса к сервису геолокации. При split tunneling этот маршрут может отличаться от маршрутов ChatGPT и STUN. Проверка HTTP или страны не подтверждает доступность голосового UDP.

Нативный клиент собирает ICE-кандидаты через `stun.l.google.com:19302/UDP` и ожидает завершения до 12 секунд. `ice_gather_timeout` возникает до обмена SDP с голосовым сервисом; повторный вход не устраняет эту ошибку.

## Проверенный случай на Мини 2

В клиенте 0.3.5 при внешнем split tunneling DNS возвращал синтетический IPv4 и IPv6 `::` для STUN, а рабочего IPv6-маршрута по умолчанию на колонке не было.

- Отдельный минимальный UDP-тест получил корректный STUN Binding Response как через синтетический IPv4, так и через публичный адрес Google STUN. Поэтому сам синтетический адрес не признан причиной отказа UDP.
- Обычный диагностический вызов завершился `ice_gather_timeout`. Существующий параметр `ALISA_ICE_BIND_ADDRESS`, установленный в текущий IPv4 колонки только для диагностического процесса, позволил получить голосовой ответ. Микрофон и вывод ALSA в этом процессе не использовались.
- После исправления запуска настоящий контроллер установил голосовое соединение: подтверждены текст и звук ответа, ненулевые микрофонные кадры и ноль ALSA underrun. Проверочный разговор закрыт; сохранённый вход и настройки сохранились.

Это подтверждает работоспособность привязки к IPv4 в указанной сети. Точная внутренняя причина задержки dual-stack ICE не устанавливалась; проверка выполнена на одной колонке.

## Выбор IPv4 при запуске

`run.sh` сохраняет явно заданный `ALISA_ICE_BIND_ADDRESS`, включая адрес TUN встроенного VLESS. Если привязки нет, он получает исходный IPv4 командой `ip -4 route get 1.1.1.1` и передаёт его только процессу нативного клиента. Команда читает таблицу маршрутов, без отправки пакетов; адрес определяется заново при каждом запуске. При отсутствии IPv4 остаётся обычное поведение клиента.

Системные настройки IPv6, DNS и маршрутизации не меняются.
