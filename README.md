# Alisa Voice

> **Поддерживаются Яндекс Станция Лайт 1, Лайт 2, Мини 2, Мини 3 и Станция 2.** Нативная установка с Windows/Linux; браузерный мост — Linux, Лайт 2 и Мини 2.

[Версия 0.3.9](docs/release-0.3.9.md): исправлены кнопки веб-панели, выбор сертификатов, запуск VPN и диагностика установки SSH-ключа.

**ChatGPT Voice на Яндекс Станции.** Настройка через CLI со стрелками, выбором параметров и предпросмотром подсветки на Лайт 1/2, кольцах Мини 2/3 и светодиодной панели Станции 2. На Мини 3 можно выбрать анимированные глаза или штатные часы.

| Режим | Как работает | Компьютер после установки |
|---|---|---|
| **Нативный** | Голосовой клиент работает на колонке | Не нужен |
| **Мост** | ChatGPT работает в фоновом Chromium на Linux, звук идёт через колонку | Нужен постоянно |

Используется аккаунт ChatGPT. API-ключ не требуется. **Free и Plus проверены в обоих режимах.** Go пока не проверен на настоящем аккаунте.

## Что нужно

- **Лайт 1, Лайт 2, Мини 2, Мини 3 или Станция 2 с уже работающими root и SSH**, доступная из сети компьютера.
- Linux x86_64 с Python 3.10+ и Chromium либо Windows x64 с Edge/Chrome для первого входа. Windows-пакет содержит Python и зависимости. Для сохранения входа в Linux нужны Xvfb и xauth; мастер предлагает их установку.
- Для моста — работающий PipeWire с PulseAudio-интерфейсом либо PulseAudio.

Совместимость прошивки и свободное место проверяются до установки. Известные пары SHA-256 `maind` и VQE отмечаются как проверенные. На другой сборке поддерживаемой модели появляется предупреждение, после которого можно продолжить установку; совместимость её аудиоинтерфейсов пока не подтверждена. Проверки модели, архитектуры, файлов и пакета остаются обязательными. Получение root в установщик не входит.

## Установка

Откройте терминал Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/rison1337/Alisa-ChatGPT-voice-assistant/main/bootstrap-linux.sh | sh
```

Команда скачает готовый [Linux-релиз](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/releases/latest), проверит пакет и откроет мастер. Компилятор, pip и API-ключ не нужны. Установка из клонированного репозитория: `./install-linux.sh && ~/.local/bin/alisa`.

Мастер сам проведёт по шагам: режим → IP, порт и пароль SSH → проверка колонки и сети → настройки → установка → вход в ChatGPT → голосовой тест. Параметры подключения запоминаются после успешной проверки; пароль SSH не сохраняется.

Войти в ChatGPT нужно один раз в отдельном окне браузера. Вход обнаруживается и сохраняется автоматически — дополнительный Enter не нужен. В нативном режиме после настройки компьютер можно выключить.

Установщик предлагает необходимые пакеты через pacman, apt-get или dnf. Полный живой прогон выполнен на CachyOS; остальные дистрибутивы пока не прошли такой же прогон. Подробности установки и ограничения Chromium: [инструкция Linux](docs/linux-install.md).

В Windows скачайте [ZIP последнего релиза](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/releases/latest/download/alisa-voice-windows.zip), распакуйте папку целиком и запустите `START-WINDOWS.cmd`. Права администратора для приложения не нужны. Python и библиотеки находятся в комплекте. В мастере укажите IP, порт и пароль SSH колонки; вход в ChatGPT откроется в браузере.

## Обновления

При запуске CLI предлагает новую опубликованную версию: **«Обновить»**, **«Не сейчас»**, **«Больше не спрашивать»**. Последний вариант отключает предложения; включить их снова можно в **«Установка и обслуживание → Обновления программы»**. Там же доступна ручная проверка.

```bash
alisa update                 # проверить и предложить установку
alisa update check           # только сведения о версии
alisa update ask-on          # вернуть предложения при запуске
```

Программа обновляет себя на компьютере и компоненты установленных режимов с сохранением настроек, входа и чатов. Для компонентов нужен SSH к колонке. Голосовой чат перед обновлением нужно закрыть. Предыдущая программа сохраняется для отката; автоматической установки в фоне нет. Для перехода со старой версии без этого меню один раз запустите новый установщик. [Как работает обновление](docs/updates.md).

**Уже установлена Linux 0.2.0?** Остановите текущий режим и повторите команду установки выше. В новом CLI выберите «Настроить / переустановить» для компонентов колонки. Настройки и сохранённый вход останутся. [Переход со старой версии](docs/linux-install.md#обновление-поверх-linux-020).

## Управление голосом

| Команда | Действие |
|---|---|
| «Алиса, открой чат» | Продолжить разговор с GPT |
| «Алиса, создай новый чат» | Начать новый разговор |
| «Алиса, открой предыдущий чат» | Вернуться к предыдущему разговору |
| «Алиса, закрой чат» | Вернуть обычную Алису |

Фразы после обращения «Алиса» меняются в CLI. Фразы и подсветка применяются без перезапуска клиента и текущего разговора; неизменённые параметры повторно не записываются. Там же доступны подсветка с живым демо, автозапуск, смена аккаунта, обновление, диагностика и удаление. Голос нативного клиента выбирается в CLI; голос моста задаётся в настройках сайта ChatGPT.

В нативном режиме музыка ставится на паузу при входе в GPT. В «Настройках → Подсветка» можно выбрать цвет и анимацию, а также когда их показывать: только во время ответа (по умолчанию) или ещё при прослушивании и ожидании ответа. Прежняя голубая волна в паузах доступна отдельно; сохранённые настройки не меняются.

Несколько нативных колонок выбираются пунктом **«Колонка»** в главном меню или командой `alisa native devices`. У каждой отдельные настройки, SSH и вход ChatGPT; существующая колонка остаётся профилем `default` в прежней папке. Переключение не останавливает разговоры. [Профили и обновления](docs/cli-reference.md#несколько-нативных-колонок).

```bash
~/.local/bin/alisa
```

Нативный режим поддерживает VLESS для трафика GPT: отдельную ссылку или подписку с выбором сервера. При потере VPN прямого подключения не происходит, управление возвращается Алисе. Проверка сети показывает страну выхода: для RU предлагает VPN. Голос проверяется отдельно после входа. В сетях с внешним VPN проверка страны не подтверждает доступность голосового UDP. [Настройка сети и диагностика ошибок Voice](docs/native-network.md).

Обновление и обычное удаление программы сохраняют аккаунт, чаты и SSH. Автозапуск можно включить и выключить отдельно. В меню VPN есть переключатель автозапуска VLESS и удаление его программы и активных настроек. Повторный мастер нативного режима пропускает совпадающие файлы и сохраняет вход и чаты. Для голосовых команд нужен доступ колонки к сервисам Алисы.

**Оба режима можно держать установленными.** Для переключения остановите текущий в CLI и запустите другой. Настройки и входы раздельные; одновременно микрофонами и динамиком управляет один режим. Автозапуск выбирается для одного режима: включение второго отключает первый.
