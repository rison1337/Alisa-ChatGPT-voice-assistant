# Alisa Voice

> Локальная тестовая ветка Windows: пока только нативный установщик.
> Запуск подготовленного пакета — `START-WINDOWS.cmd`.
> План проверки и передача работы другому Codex — `CODEX-HANDOFF` на флешке.
> Windows-сборку не публиковать. Ниже сохранена документация исходной Linux-версии.

**ChatGPT Voice на Яндекс Станции Лайт 2.** Настройка через CLI со стрелками, выбором параметров и предпросмотром подсветки на колонке.

| Режим | Как работает | Компьютер после установки |
|---|---|---|
| **Нативный** | Голосовой клиент работает на колонке | Не нужен |
| **Мост** | ChatGPT работает в фоновом Chromium на Linux, звук идёт через колонку | Нужен постоянно |

Используется аккаунт ChatGPT. API-ключ не требуется. **Free и Plus проверены в обоих режимах.** Go пока не проверен на настоящем аккаунте.

## Что нужно

- **Станция Лайт 2 с уже работающими root и SSH**, доступная из сети компьютера.
- Linux x86_64, Python 3.10+ и рабочий стол для первого входа в Chromium.
- Для моста — работающий PipeWire с PulseAudio-интерфейсом либо PulseAudio.

Совместимость прошивки и свободное место проверяются до установки. Сейчас поддержана проверенная сборка Лайт 2; другие сборки могут потребовать адаптации аудиомодулей. Получение root в установщик не входит.

## Установка

Откройте терминал Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/rison1337/Alisa-ChatGPT-voice-assistant/main/bootstrap-linux.sh | sh
```

Команда скачает готовый [Linux-релиз](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant/releases/latest), проверит пакет и откроет мастер. Компилятор, pip и API-ключ не нужны. Установка из клонированного репозитория: `./install-linux.sh && ~/.local/bin/alisa`.

Мастер сам проведёт по шагам: режим → IP, порт и пароль SSH → проверка колонки и сети → настройки → установка → вход в ChatGPT → голосовой тест. Параметры подключения запоминаются после успешной проверки; пароль SSH не сохраняется.

Войти в ChatGPT нужно один раз в отдельном окне браузера. Вход обнаруживается и сохраняется автоматически — дополнительный Enter не нужен. В нативном режиме после настройки компьютер можно выключить.

Установщик предлагает необходимые пакеты через pacman, apt-get или dnf. Полный живой прогон выполнен на CachyOS; остальные дистрибутивы пока не прошли такой же прогон. Подробности установки и ограничения Chromium: [инструкция Linux](docs/linux-install.md).

## Управление голосом

| Команда | Действие |
|---|---|
| «Алиса, открой чат» | Продолжить разговор с GPT |
| «Алиса, создай новый чат» | Начать новый разговор |
| «Алиса, открой предыдущий чат» | Вернуться к предыдущему разговору |
| «Алиса, закрой чат» | Вернуть обычную Алису |

Фразы после обращения «Алиса» меняются в CLI. Фразы и подсветка применяются без перезапуска клиента и текущего разговора; неизменённые параметры повторно не записываются. Там же доступны подсветка с живым демо, автозапуск, смена аккаунта, обновление, диагностика и удаление. Голос нативного клиента выбирается в CLI; голос моста задаётся в настройках сайта ChatGPT.

```bash
~/.local/bin/alisa
```

Нативный режим поддерживает VLESS для трафика GPT: отдельную ссылку или подписку с выбором сервера. При потере VPN прямого подключения не происходит, управление возвращается Алисе. Проверка сети показывает страну выхода: для RU предлагает VPN. Голос проверяется отдельно после входа.

Обновление и обычное удаление программы сохраняют аккаунт, чаты и SSH. Автозапуск можно включить и выключить отдельно. В меню VPN есть переключатель автозапуска VLESS и удаление его программы и активных настроек. Повторный мастер нативного режима пропускает совпадающие файлы и сохраняет вход и чаты. Для голосовых команд нужен доступ колонки к сервисам Алисы.

**Оба режима можно держать установленными.** Для переключения остановите текущий в CLI и запустите другой. Настройки и входы раздельные; одновременно микрофонами и динамиком управляет один режим. Автозапуск выбирается для одного режима: включение второго отключает первый.
