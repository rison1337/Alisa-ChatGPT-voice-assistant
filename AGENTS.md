# Alisa Voice

- Ветка Windows-установщика, адаптации Лайт 1 и обновлений Linux/Windows. Владелец 30.10.2026 разрешил публикацию предпросмотра в приватном rison1337/Alisa-Voice-preview. Публичные push/merge/release и закрытие issue #2 — следующий этап после проверки обновления.
- Windows-мост не входит в текущий этап. При подготовке в Linux КВМ и её диски не запускать и не изменять.
- При проверке в Windows тестировать только приложение и колонку; настройки КВМ, образы и виртуальное железо не менять.
- Передавать результат через отдельную папку на флешке вместе с TXT-инструкцией для Codex.
- Не добавлять пароли, токены, браузерные профили, SSH-ключи, подписки VPN, дампы прошивки и локальные исследования.
- Получение root не входит в установщик; требуются готовые root и SSH. Неизвестная пара хешей Лайт 1/2 допускается с предупреждением по явному решению владельца. Нативный режим — Лайт 1/2, мост — только Лайт 2. Модель, архитектура, файлы и целостность пакета остаются обязательными проверками.
- Нативный режим и Linux-мост имеют отдельные настройки; одновременно колонкой владеет один режим.
- VPN применяется только к GPT; при отказе туннеля прямое подключение запрещено.
- Сохранять аккаунты, чаты, SSH и неизвестные пользовательские файлы при обновлении или удалении.
- Нативный установщик и updater проверены на одном Windows 11 x64 с Edge/Лайт 2; возвращённое исправление launcher импортировано локально. Новая политика неизвестной прошивки проверяется на фикстурах Linux/Wine. Не распространять результат на Windows 10, все браузеры и Лайт 1. Живой Go-аккаунт не проверен.
- Сведения о Лайт 1 получены из PR #1; собственной проверки на её аппаратуре нет. Не объявлять программную кнопку mute проверенной в GPT.
